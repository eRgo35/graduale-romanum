# Missa I *Lux et origo* (Tempore paschali)

Booklet with the Ordinary of Missa I in modern notation, Latin text with
Polish translation in parallel columns. Pitch and layout follow the Vatican II
Hymnal (2011, pp. 159–162); the Ite, missa est, absent from the Hymnal, is
pitched like the Kyrie.

| Chant | Mode | gabc source |

## Layout

- `gabc/`: square-notation sources from GregoBase, edited to the Hymnal.
- `scores/`: `.ly` scores generated by `../tools/gabc2ly.py`.
- `missa-i.tex`: LuaLaTeX booklet embedding the scores via `lyluatex`.
- `missa-i.pdf`: built booklet.

## Build

```sh
make         # regenerate changed scores, then build missa-i.pdf
make clean   # remove build-ly/ cache and LaTeX outputs
```

Per-chant converter options (pitch, key signature) are set in the `Makefile`.
Transpose a chant by changing its `--do` pitch, e.g. `--do "c'"`.
